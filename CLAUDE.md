# Notes for Claude

- Godot 4.6.2, GDScript, Forward+ renderer. PC only.
- The owner tests in the Godot editor; Claude can't see the game. Validate changes headless before pushing:
  `godot --headless --path . --import` then run a smoke-test `SceneTree` script.
- Prefer generating complex `.tscn` files with a headless build script over hand-writing them.
- Typed GDScript (`:=`, typed params), tabs for indentation, `class_name` on reusable scripts.
- Physics layers: 1 world, 2 players, 3 enemies.
- Character rig: Mixamo (`mixamorig:` bones), shared by masc and femme bodies. Femme body parts are prefixed `f_`.
- Design doc lives as a Claude doc ("Titamas Online — Design Doc"); README has Blender and level-chunk conventions.
- Visual checks: `xvfb-run -a godot --path . --rendering-driver opengl3 --script <shot.gd>` renders screenshots (software GL).
- `base_bodies.glb` holds both bodies; its import uses `root_scale=0.01` because the Mixamo bones come through in centimetres. Keep that setting if the file is re-exported the same way.
- When building scenes by script, never set `owner` on nodes inside an instanced scene (causes duplicate-node load errors).
- Animations: Mixamo FBX (Without Skin) go in `assets/animations/mixamo/`; run `godot --headless --path . --script res://tools/godot/retarget_mixamo.gd` to rebuild `masc.res`/`femme.res`. Looping/in-place lists live at the top of that script. Facing is derived from hip anatomy, not bone axes.
- `PlayerAnimator` picks animations from movement; `CharacterModel.play()/play_from()` crossfade. Animations only run in-game (not in the editor) so bone poses never get saved into scenes.
- Player states (PlayerController.State): NORMAL, DODGE, HANG, LEDGE_CLIMB, WALL_CLIMB, LADDER, SWIM. Groups `climbable`/`ladder` mark surfaces; `WaterVolume` (physics layer 4) marks water. One-shot moves emit `action_animation`; continuous states call `character.play()` directly.
- Converter extras: `ROOT_MOTION` (travel baked to metadata), `YAW_FIX` (clips facing backwards), `HEIGHT_MATCH`, `ARM_SPREAD`.
- World: `Ocean` (group "ocean", sea level −5 m) follows the player; `_water_at()` treats anything below sea level as water. Fatigue builds when swimming >48 m from the nearest chunk; kill floor at −80 m; both respawn at the last dry ground. `AtmosphereManager` blends `RegionAtmosphere`s (built from data/regions.json, chunk rectangles) and shows the zone name.
- Chunk materials are swapped by name for `assets/materials/terrain/<name>.tres`; chunk meshes named `*-water` become water (shader + swimmable `WaterVolume`).
- Props: `chunk_I_J.props.json` beside each chunk lists {name, pos, basis columns} in chunk space; `PropLibrary` loads `assets/props/<name>.glb`, applies `foliage_wind.gdshader` to foliage names and adds collision (tree trunk cylinder / convex hull / none). JSON files must be included when exporting the game (Export → Resources → filters: `*.json`).
- Sound: buses Master/Music/SFX/Ambience (`default_bus_layout.tres`). `PlayerAudio` (under Player) times footsteps/strokes/grabs from `CharacterModel.bone_contacts()` and picks the surface from `ChunkStreamer.paint_at()` (terrain UV2 paint), slope, `surface` metadata (props get it from `PropLibrary.surface_of`), group `ladder`, water. Region ambience + altitude wind in `AtmosphereManager`, surf in `Ocean`. Generated sounds: `tools/audio/make_ambience.py` (numpy + ffmpeg). Credits in `assets/audio/CREDITS.md`. Headless quit() while loops play prints a harmless "resources still in use" leak warning.
- Combat: anything fighting is in group `combatants` with a `Stats` child (display_name, level, team PLAYERS/ENEMIES, `immortal`, heal-over-time). `Combat` (static) finds enemies, scales damage by level, applies hits (target may implement `modify_incoming_damage` / `stagger`), plays sounds, spawns numbers. `Ability` objects from `data/abilities.json` (MELEE / PROJECTILE / HEAL_OVER_TIME) are run by `PlayerCombat`; `Targeting` handles Tab/click/auto-target. PlayerController has states ACTION (attacks/casts/block; dodge cancels via `action_interrupted`) and DEAD. Enemies: `Enemy` (CharacterBody3D, layer 3, AI IDLE/CHASE/ATTACK/STAGGER/RETURN/DEAD) and `TrainingDummy`; `Nameplate` over them. Placeholder combat clips come from `PLACEHOLDERS` in `retarget_mixamo.gd` (an FBX of the same name overrides). Weapons are stand-in meshes from `WeaponModels`, held via `CharacterModel.attach_to_hand()` (grip worked out from finger bones; bodies have thumb/index/ring only) and sheathed on the back via `attach_to_bone()` outside combat. Test with `InputEventAction` through `Input.parse_input_event` for "attack" (it's read in `_unhandled_input`).
- Controls (Fable style, see design doc): one `attack` action, meaning set by `PlayerCombat.mode` (MELEE/RANGED/MAGIC; `cycle_mode`, `spell_prev/next`); tap < `tap_time` = quick, hold = charge (`Ability.charge_time/charge_power/max_charge_level`). `block`, `dodge`, `sprint` (controller = toggle), `target_prev/next`, `lock_on` (Targeting.locked → `player.lock_target`, camera frames target). Stamina = sprint only. Input map has keyboard/mouse and joypad events (device -1).
- `GameSettings` autoload: volumes (buses incl. Footsteps), pixel textures (global shader uniform `pixel_texels`, `pixel_sample.gdshaderinc`; props use `pixel_scale`), camera sensitivity/invert, bindings; saved in user://settings.cfg. `menu_open` blocks gameplay input. `SettingsMenu` (gear icon) is built by the HUD. In `--script` tests use `root.get_node("GameSettings")`.
- Region looks also set shadow strength (sun shadow_opacity) and saturation/contrast/brightness (Environment adjustments).
- Data: `data/abilities.json`, `enemies.json`, `player.json`, `regions.json` are the source of truth (no .tres for these). `DataFiles` (@tool static) converts JSON <-> Godot (colours "#rrggbb", sounds res:// paths, enums lowercase). `Database` autoload builds `Ability` objects (same instances for the session), applies enemy entries (`Enemy.enemy_id`) and the player entry (stats/movement/combat/loadout), and live-reloads changed files once a second when run from the editor (`changed` signal). `AtmosphereManager` reads regions.json itself (works in the editor preview too); the entry with `"default": true` is the open sea.
- Database editor: `addons/titamas_database` (enabled plugin) adds a toolbar **Database** button and serves `tools/database/index.html` + `/api/data`, `/api/assets`, `/api/save` on 127.0.0.1:8787 (falls back to 8788–8790). Schemas for the page's forms are the `TABS` object at the top of its script: add fields there when adding data fields.
- World look: `WorldCycle` (@tool, group "world_cycle", in the overworld) runs time of day (sun + its own Moon light, sky shader uniforms `use_cycle/sun_direction/moon_direction/night_amount`, stars) and wind (global uniform `wind_strength`), settings in data/world.json. `AtmosphereManager._apply` passes region values through `WorldCycle.apply_time()`; it also drives volumetric fog god rays (region `god_rays`, setting `GameSettings.god_rays`) and global uniforms `grass_base/grass_tip`. Grass: `GrassField` tiles (16 m MultiMesh, `grass.gdshader`, global `player_position` push) built by ChunkStreamer from per-chunk height/paint grids (`_read_terrain`) for chunks within `grass_radius`, a few tiles per frame; density = region `grass_density` x `GameSettings.grass_multiplier()`. Water: depth-based shore darkening + foam in water.gdshader; `WaterEffects` (under Player) spawns `Effects.ripple/splash`.
- Items/equipment (M3): `data/items.json` (Database `item(id)`, `stack_size`). `Inventory` node under Player (group `player_inventory`; bag of 24 {id,count}, `equipped`, `gold`, 2 quick slots; saved inside the character's save via `to_dict()`/GameSession, `reset_character()`). `PlayerGear` wears armour via `CharacterModel.wear(item, tag)` (skinned `fitted_masc/femme` scenes reparented onto the skeleton; rigid `fit.{masc,femme}` attachments {bone, grip?, position, rotation deg, scale} via `attach_fitted`; `hides` body parts). `PlayerCombat._equip_weapons` handles main_hand/ranged. `Stats.set_bonuses` adds gear stats; armour reduces damage in `Combat.hit`. `LootBag.drop_for` on enemy death (enemies.json gold_min/max, loot). UI: `CharacterWindow` (HUD-built, action `inventory`), `ItemSlot`, `ItemIcon`. Armour fitter: `scenes/tools/armor_fitter.tscn` (plugin "Fit Armor" button). In `--script` tests, don't name classes whose static functions use autoloads (Inventory, LootBag) — compile error "Identifier not found: Database".
- Front end (main scene `scenes/ui/main_menu.tscn`, `FrontEnd`): title / load / credits / creator / class pages over a 3D stage; built in code. `GameSession` autoload: current character `data` and `path` (user://saves/*.json: name, pronouns, class, look, level, inventory, scene, position, play_time), `new_character`, `load_save`, `start_game` (places Player before the level enters the tree so ChunkStreamer loads there), `save_game` (autosave 60 s, window close), `quit_to_title`. Without a session (F6) nothing is saved. Appearance: `data/appearance.json`; `Database.resolve_appearance(look)` → `CharacterModel.apply_appearance()` (height = node scale, `weight` -1..1 morphs body + skinned gear along pooled normals via `_build_factor`, or "thin"/"heavy" shape keys; hair/facial hair worn as tags "hair"/"facial_hair" with `tint`; eyes = two quads fitted to the head mesh with `eye.gdshader`). Placeholder hair/beards: `tools/godot/make_appearance.gd`; eyes: `tools/art/make_eyes.py`; rigid hair builtins in `WeaponModels` (`builtin:hair_long/ponytail/bun`). Classes: `data/classes.json` (Database tab). In `--script` tests autoload data isn't loaded during `_initialize`; act from the first frame.
- Combat feel: `Combat.hit(source, target, power, stagger, knockback)` → `Combat.impact()` (sparks, `Effects.flash`, `apply_knockback`, and for the player `TimeFX.hit_stop` + camera `shake` via group "player_camera"). `TimeFX` (node under root) owns Engine.time_scale (hit-stop, `slow_motion`). `Combat.incoming_heavy` is true during `modify_incoming_damage` for staggering hits. PlayerCombat: parry (`_block_started` within `parry_window`), `grant_counter()` (parry/perfect dodge → next hit ×1.75), `_flourish` (full heavy charge), spells cast via the charge path with `Ability.cast_time` (`is_casting()`, `_auto_release` on tap, move cancels, pushback/`_interrupt`, signal `cast_interrupted`), `_buffer_until` (attack during dodge). Enemies: every `heavy_every`th attack is heavy (telegraphed flash, staggers). Test scripts: load Combat with `load()` (it references PlayerController, which uses autoloads).
- NPCs: `scenes/npcs/npc.tscn` + `Npc` (scripts/npc/npc.gd), data `data/npcs.json` (`Database.npc(id)`, Database tab with `lookopt`/`lines` field types). Team PLAYERS, layer 2; joins `combatants` only if `can_fight`; AI IDLE (stand/wander/patrol via `Patrol/Marker3D`)/FIGHT/FLEE/RETURN/TALK/DEAD; skips group `practice_targets` (training dummy). Talking: group `talkable`, `PlayerController._try_talk()` on jump (player is in group "player"); `DialogueBox.open()` sets `menu_open`, fills `{player}`/pronoun tokens; `DialogueBox.closed_at` stops the closing press from re-opening or jumping.
