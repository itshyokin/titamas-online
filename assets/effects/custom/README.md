# Your own effect sprites

PNG files in this folder show up in Database → Abilities → Effect sprites (and "Load PNG…" there saves into it).

- Any size; a see-through background. Pixel art stays crisp (no smoothing).
- **Glow** look: drawn brighter-on-top and tinted with the ability's colour: draw in white / greys.
- **As drawn** look: shown exactly as painted, colours and outlines included.
- Animated: put the frames side by side in one row, all the same size, and set **Frames** to how many there are.
- Ground sprites (decals) are seen from above: draw them as if looking straight down.
